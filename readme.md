CoList is a collaborative way for users to manage sharable shop lists.

## Features

### B2C

- Create, share and edit shop lists with others
- Each list provides dedicated chat room for discussion
- AI Suggestions for new items
- Add-from-chat for quick addition of items, straight from the chat

### B2B

- Anonymous, data-driven statistics based on "the next day"
